FEETA API Flow Reference

This page explains what the Laravel backend currently exposes, which APIs the Vue admin panel uses, and which user-auth APIs are disabled.

Last verified: June 24, 2026. The admin panel login is active. Public user login and email OTP sending are temporarily commented out.

Admin, role, permission and news APIsActiveProtected with Sanctum and role/permission middleware.

Vue Admin Session Flow

1. LoginCall POST /admin/auth/login.
2. StoreSave token, admin data and permissions in local storage/store.
3. RefreshIf token exists, load profile and permissions without sending the user back to login while requests are loading.
4. LogoutClear local auth only on explicit logout or an API 401.
A 403 means authenticated but not permitted. A 401 means the token is missing, invalid or expired.

Common Response Rules

StatusMeaningFrontend action
200/201SuccessUse response data.

422Validation errorRender field errors from errors.

Quick Team Answers

QuestionAnswer
What is the admin login API?POST https://feeta.cloud/admin-api/api/v1/admin/auth/login
Is user login active?No. POST /auth/login is temporarily commented.
Is MSG91 OTP active?No. Sender code remains, but POST /auth/send-email-otp is commented.
Is OTP verification available?No verify-OTP endpoint exists yet.
How is admin access controlled?Laravel Sanctum bearer token plus role/permission middleware.
Should frontend log out on 403?No. Only explicit logout or 401 should clear authentication.
Are public news APIs authenticated?No. GET /news and GET /news/{slug} are public.
Where are secrets stored?Backend .env only. Never in Vue, docs, WhatsApp or Git.
